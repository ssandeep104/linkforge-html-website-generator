The app in one line

What we're improving

Linkforge is a fully client-side tool: paste messy HTML (or upload .html), it extracts links, images and video previews (reading JSON-LD/OpenGraph for rich titles & hero images), you curate the picks, and it ships a single portable HTML watchlist/gallery from one of six responsive templates. Two things carry the product: HTML parsing and template generation.

Current look: dark near-black canvas with warm radial glows, an OrangeRed (~#FF4500) primary accent and cyan/teal secondary in the output, bold geometric display type paired with monospace labels, big rounded cards, and a clean 01→02→ship wizard. The direction is strong — the opportunity is polish: consistent tokens, richer cards, micro-interactions, and more distinctive output templates.

Themes that showed up everywhere

Dark-first with a bold accent
Every standout uses dark backgrounds, subtle gradients/glow, and one vivid accent for CTAs & highlights — exactly Linkforge's instinct. Add a disciplined secondary (the existing cyan) for output.
Rounded card grids
8–16px radii, generous padding, hover elevation/glow, image+text pairing. The backbone of both the review screen and the generated gallery.
Type hierarchy: display sans + mono labels
Bold geometric headings over monospace metadata (counts, step markers) — a pattern Linkforge already leans into and should systematize.
Micro-interactions signal quality
200–300ms transitions, hover states, entrance fades. Cheap to add, big lift to perceived polish across the wizard.

A concrete plan

Where the three passes agree, and the shortest path to a visible upgrade.

Engine (parsing & generation)

  1. Adopt Metascraper for unified metadata (OpenGraph + JSON-LD + Twitter Cards + Microdata) with smart fallbacks — directly upgrades preview quality. 142.8K weekly downloads
  2. Layer Mozilla Readability to clean extracted titles/descriptions (strip nav, ads, boilerplate).
  3. Watch performance with LinkedOM as a lighter DOM parser if large pastes get slow (client-side friendly).
  4. Study eleventy-photo-gallery & GlassLink-Bio for responsive gallery CSS and a modern single-file link-in-bio output — the closest analogues to Linkforge's six templates.

Interface & output polish

  1. Define design tokens (color, spacing, radius, type) — model on shadcn/ui & Semi Design so the wizard and output stay consistent.
  2. Enrich cards & hover states using Tabler / cult-ui / HeroUI patterns for the review grid and gallery.
  3. Add micro-interactions (step transitions, button/input feedback) inspired by Inspira UI and the 3D-portfolio motion work.
  4. Refresh the six output templates against Multiverse, Lens, and Folio (gallery) and GlassLink-Bio (link hub) so exports feel premium out of the box.
  5. Sharpen the landing/wizard with hero & feature patterns from Launch UI, Square UI, and AI-Agent kits.
