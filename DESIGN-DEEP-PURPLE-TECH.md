# Deep Purple Tech visual iteration

This branch contains a reviewable visual iteration of the existing LinkForge application shell.

## Preview

Open `/design-preview.html` instead of `/index.html`.

The preview loads the existing application and injects `deep-purple-tech.css`, preserving the current parser, review workflow, generated-template logic, and output behavior.

## Visual direction

- Deep near-black and midnight-purple surfaces
- Restrained violet primary actions
- Cyan used selectively for status and secondary emphasis
- Space Grotesk for product typography
- IBM Plex Mono for technical labels and metadata
- Sharper geometry, thin borders, restrained glow, and subtle grid texture
- No generated-template redesign in this iteration

## Review checklist

- Input screen hierarchy and source composer
- Review screen editor/preview split
- Template selection and active states
- Light/dark theme behavior
- Mobile Edit/Preview switching
- Focus visibility and text contrast

The production entry point remains unchanged until this visual direction is approved.
